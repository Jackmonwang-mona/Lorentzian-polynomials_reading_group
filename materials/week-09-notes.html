Different ways to define a matroid

This week's event is hosted by Jackmon.

This week, we discussed four different ways to define a matroid, as well as the operations of deletion and contraction.

We began with the independent set definition. From there, we introduced the concepts of bases, circuits, and rank functions, exploring how a matroid can be defined using each of these structures independently. To help solidify these concepts, we walked through a few examples, such as uniform matroids and graphic matroids.

Finally, we introduced the deletion and contraction operations, examining them more comprehensively within the specific context of graphic matroids.
